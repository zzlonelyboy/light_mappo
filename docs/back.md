当前实验主线、已完成工作与结果总结

## 摘要

摘要：随着无人机集群在巡检、物流和协同感知等场景中的广泛应用，GPS欺骗对导航与编队协同构成威胁。现有信号级方法依赖原始GNSS观测量或专用接收处理，多源融合方法则需要惯导、视觉等辅助信息，增加部署与处理开销。当前基于学习的检测器大多采用逐时间步分类损失，而实际系统通常在连续多步异常后触发报警，训练目标与事件级报警规则存在差异。为此，本文提出一种通感一体化（ISAC）辅助的GPS欺骗事件检测方案。该方案利用多基站距离、径向速度和方向测量构造GPS与ISAC物理一致性残差，并引入目标中心邻域异常对比特征，在感知质量下降时补充单机证据。随后，采用门控循环单元（GRU）学习异常的时序演化，通过基于Soft-Min的可微连续确认映射，使模型训练与连续多步报警规则相匹配。多类攻击和不同感知质量下的仿真结果表明，多基站物理一致性残差是主要判别依据。事件对齐训练在基本保持事件召回率的同时，提高了事件级精确率和F1，并降低了误报。邻域特征主要在ISAC感知质量较低时抑制误报，在较高质量条件下未表现出稳定增益。在具备ISAC基础设施的场景中，该方法可减少对附加机载传感器的依赖，并提高事件级报警的可靠性。

## 1. 当前主线结论

当前论文可以围绕以下主线组织：

> 利用多基站 ISAC 测量为 GPS 提供独立的物理一致性参照，以 GRU 学习异常的时序演化；进一步通过与连续 $K$ 步确认规则对齐的事件损失，改善事件级 Precision、F1 和误报率；邻域异常对比作为条件性辅助信息，在部分困难条件下补充本机物理证据。

三部分的功能关系为：

$$
\boxed{
\text{多基站 ISAC 残差：提供主要检测证据}
}
$$

$$
\boxed{
\text{事件对齐损失：改善 Precision--FAR 权衡}
}
$$

$$
\boxed{
\text{邻域异常对比：提供条件性补充信息}
}
$$

从当前已经完成的实验看：

1. **事件损失的证据链已经较完整。** 已完成 BCE、Weighted BCE、Focal Loss、BCE+Early、BCE+FA 和完整 Event Loss 的对比。
2. **ISAC 特征的主要作用已经得到清楚验证。** 移除 6 维基站残差后，检测性能明显下降。
3. **邻域特征只能定义为条件性贡献。** 在 RCS=6 主条件下平均增益较小；在部分低质量或特定攻击条件下能够降低误报，但并非所有条件下均有效。
4. **攻击类型和强度分层已经完成。** 弱攻击主要体现为 Recall 较低或首次报警延迟较长。
5. **RCS 质量分析已经形成两种互补实验。** Matched-RCS 用于说明不同质量条件下可达到的性能；固定 RCS=6 模型跨 RCS 测试用于说明部署时质量失配的鲁棒性。

因此，核心方法已经具备形成论文实验主线的条件；尚未完全闭环的部分主要是当前主模型的多轨迹外部测试、1 小时多攻击测试和最终论文资产统一。

### 2.4 当前完整训练目标

当前 Event Loss 为：

$$
\mathcal L
=
\mathcal L_{\mathrm{BCE}}
+
\lambda_d\mathcal L_{\mathrm{early}}
+
\lambda_f\mathcal L_{\mathrm{FA}},
$$

其中：

$$
\lambda_d=0.01,
\qquad
\lambda_f=0.5.
$$

当前没有启用独立的检测似然项：

$$
\lambda_{\mathrm{det}}=0.
$$

因此，方法的实际重点是：

- BCE 保证基础逐步分类能力；
- Early 项提供较早确认倾向；
- FA 项抑制正常区间形成正式误报事件。

## 5. Event Loss 组成消融

### 5.1 Early 项

BCE+Early 相对 BCE：

- Recall 提高约 0.25 pp；
- 平均延迟缩短约 0.054 s；
- Precision 下降约 2.09 pp；
- F1 下降约 1.02 pp；
- FAR 增加约 26.9%。

这说明 Early 项确实产生了更激进的早报警倾向，但单独使用会增加误报。

### 5.2 FA 项

BCE+FA 相对 BCE：

- Precision 提高约 3.79 pp；
- F1 提高约 1.85 pp；
- FAR 降低约 45.4%；
- Recall 仅下降约 0.29 pp；
- 平均延迟增加约 0.029 s。

因此，当前 Event Loss 总体增益的主要来源是事件级误报约束。

### 5.3 完整 Event Loss

完整 Event Loss 相对 BCE+FA：

- Precision 继续提高约 0.87 pp；
- F1 继续提高约 0.36 pp；
- FAR 继续降低约 18.3%；
- Recall 下降约 0.18 pp；
- 平均延迟增加约 0.042 s。

Early 和 FA 联合使用取得了当前最好的 F1 与 FAR，但不是最短延迟。

$$

$$

核心观察：

- RCS=1 时发生严重质量失配，F8/F9 的 Event F1 分别约为 0.193/0.234；
- RCS=3 时 F9 相对 F8 将 Event F1 从约 0.754 提高到 0.849，并将 FAR 从约 8.544 降至 4.095；
- RCS=6 时两者性能接近，F9 仅小幅降低 FAR；
- RCS 高于训练条件后，F8 的 F1 持续提高，而 F9 因邻域特征分布失配出现 Precision/FAR 恶化。

因此，当前邻域结论应限定为：

> 邻域异常对比在部分退化条件下能够缓解本机证据不足导致的误报，但对训练时 ISAC 质量分布敏感。

不能写成：

> ISAC 质量越低，邻域特征的增益必然越大。

## 11. 当前可以支撑的论文结论

### 11.1 强证据

1. 多基站 ISAC 残差是当前检测器的主要物理信息来源。
2. Event Loss 相对 BCE 能够提高 Event Precision 和 Event F1。
3. Event Loss 能够显著降低 FAR，同时仅小幅牺牲 Recall。
4. FA 项是完整 Event Loss 性能改善的主要来源。
5. 方法可以检测 Random、Replay 和 Stealth 三种攻击。
6. 弱攻击通常表现为较低 Recall 或较长首次报警延迟。
7. ISAC 测量质量提高能够改善整体性能并缩短延迟。

### 11.2 条件性证据

1. 邻域异常对比可在部分条件下提高 Precision、F1 或降低 FAR。
2. 邻域作用依赖攻击类型、攻击强度和测试时 ISAC 质量。
3. RCS=3 和部分 Replay/Stealth 子组呈现较清楚的邻域增益。
4. 邻域特征不应被描述为所有条件下都有效的普遍增强模块。

### 11.3 当前证据不支持

1. Event Loss 能够缩短总体平均检测延迟；
2. 邻域特征在所有 RCS、攻击类型和强度下均提高性能；
3. 邻域增益随 RCS 单调下降；
4. $k_n=3$ 是普遍最优邻域规模；
5. 当前模型与轨迹类型无关；
6. 当前数值仿真已经等价于真实飞行或硬件实验。

### 14.1 已确认一致

## 17. 当前汇报用总结

> 当前实验已经形成较清晰的证据链：多基站 ISAC 残差提供 GPS 欺骗检测的主要物理依据；与连续 $K$ 步报警规则对齐的事件损失，相比 BCE、Weighted BCE 和 Focal Loss，能够在基本保持高 Recall 的同时提高事件 Precision 和 F1，并显著降低 FAR。损失组成消融进一步表明，FA 项负责主要误报抑制，Early 项则产生较早但更激进的报警倾向。邻域异常对比不是主要检测来源，而是在部分 ISAC 退化、攻击类型和攻击强度条件下提供补充信息。攻击分层结果显示，弱攻击主要带来更低的 Recall 或更长的首次报警延迟。当前核心实验已经完成，下一步重点是补齐统一的多轨迹外部测试、1 小时多攻击测试，并重新生成与 RCS=6 主线一致的最终论文表格和图像。
