# ISAC 欺骗检测实验结果总结



## 1. 实验设置与指标口径

### 1.1 三种特征配置

| 简称 | 配置 | 维度 | 内容 |
|---|---|---:|---|
| Position Only | Only Position | 2 | GPS 与基站 ISAC 位置差异 |
| Local | Local | 8 | 6 维基站 ISAC 统计量 + 2 维位置差异，不使用邻机特征 |
| Full | Full | 10 | Local 特征 + 2 维机间 ISAC 测距一致性特征 |

模型均在 RCS=6 的训练集上训练。Full 模型的基准邻域大小为 $K_n=3$。

部署时使用连续 $K_c=5$ 步确认报警；这里 $K_n$ 表示邻机数量，$K_c$ 表示报警确认步数。

### 1.2 指标解释

| 指标 | 含义 |
|---|---|
| Event Precision | 事件级报警精确率 |
| Event Recall | 事件级攻击召回率 |
| Event F1 | Event Precision 与 Event Recall 的调和平均 |
| FAR | 每无人机小时的误报警事件数 |
| DR@1s | 攻击开始后 1 秒内完成检测的事件比例 |
| Mean Delay | 已成功检测事件的条件平均延迟 |

## 2. 训练目标
### 2.1 当前的训练目标
当前 Event Loss 为：

$$
\mathcal L
=
\mathcal L_{\mathrm{BCE}}
+
\lambda_d\mathcal L_{\mathrm{early}}
+
\lambda_f\mathcal L_{\mathrm{FA}},
$$

其中：

$$
\lambda_d=0.01,
\qquad
\lambda_f=2.
$$

因此，方法的实际重点是：

- BCE 保证基础逐步分类能力；
- Early 项提供较早确认倾向；
- FA 项抑制正常区间形成正式误报事件。

### 2.2 损失函数总体比较
- RCS=6 主数据集,使用相同的测试数据

| 方案             | Event Precision   | Event Recall      | Event F1          | FAR (/UAV·h) ↓    | DR@1s             | Mean Delay (s) ↓  |
| ---------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- |
| BCE              | 0.899 ± 0.010     | 0.997 ± 0.001     | 0.946 ± 0.006     | 1.637 ± 0.181     | 0.695 ± 0.004     | 1.273 ± 0.029     |
| Weighted BCE     | 0.532 ± 0.035     | **0.999 ± 0.000** | 0.693 ± 0.030     | 13.011 ± 1.809    | **0.889 ± 0.007** | **0.631 ± 0.021** |
| Focal            | 0.892 ± 0.019     | 0.997 ± 0.001     | 0.942 ± 0.010     | 1.782 ± 0.342     | 0.706 ± 0.008     | 1.246 ± 0.052     |
| Event-Likelihood | **0.962 ± 0.016** | 0.989 ± 0.002     | **0.975 ± 0.009** | **0.574 ± 0.242** | 0.655 ± 0.021     | 1.699 ± 0.151     |

>传统 BCE、Weighted BCE 和 Focal Loss 均以单个时间步为优化单位，而系统在部署时采用连续 $K_c=5$ 步确认并按事件统计性能，两者的粒度差异使少量连续误判也可能形成完整的误报警事件。BCE 和 Focal Loss 的结果接近，Weighted BCE 虽提高了召回率和早期检出率，却使 FAR 增至 13.011 次/UAV·h，说明调整逐步分类权重不能解决事件级误警问题。当前 Event-aligned Loss 在 BCE 基础上加入首次报警时刻和正常区间无报警约束，使 Event Precision 从 0.899 提高至 0.962、Event F1 从 0.946 提高至 0.975，同时保持 0.989 的 Event Recall。尽管其早期检出率和平均延迟略有退化，这些结果仍表明，将逐步概率学习与连续确认规则纳入同一训练目标，能够减少无效报警，并提高事件级检测的整体可靠性。

### 2.3 Event Loss 组成消融

| 方案       | Event Precision   | Event Recall      | Event F1          | FAR (/UAV·h) ↓    | DR@1s             | Mean Delay (s) ↓  | Step F1           |
| ---------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- |
| Early-only | 0.777 ± 0.022     | **0.997 ± 0.002** | 0.873 ± 0.014     | 4.219 ± 0.542     | **0.772 ± 0.021** | **1.013 ± 0.055** | **0.961 ± 0.002** |
| FA-only    | **0.979 ± 0.007** | 0.985 ± 0.003     | **0.982 ± 0.003** | **0.311 ± 0.107** | 0.573 ± 0.013     | 1.946 ± 0.098     | 0.946 ± 0.003     |
| Early+FA   | 0.962 ± 0.016     | 0.989 ± 0.002     | 0.975 ± 0.009     | 0.574 ± 0.242     | 0.655 ± 0.021     | 1.699 ± 0.151     | 0.948 ± 0.002     |

> 组成消融表明，Early 项与 FA 项分别侧重检测及时性和误报警控制。Early-only 通过优化攻击事件内首次报警的条件期望延迟，使模型更早触发，因而获得 较短的平均延迟。但该项不约束正常区间内的连续报警，当正常状态与攻击初期的特征分布重叠时，提前触发也会增加误警，使 Event Precision 降至 0.777。其 Step F1 为 0.961，而 Event F1 仅为 0.873，进一步说明较好的逐步分类结果未必能转化为可靠的事件报警。FA-only 通过抑制正常区间中可形成 $K_c$步连续触发的预测片段，将 Event Precision 和 Event F1 分别提高至 0.979 和 0.982，并将 FAR 降至 0.311 次/UAV·h，但更保守的判决也降低了早期检出率。加入 Early 项后，Early+FA 将 DR@1s 从 0.573 提高至 0.655，平均延迟缩短 0.247 s，同时 Event F1 降至 0.975、FAR升至0.574次/UAV·h。因此，完整损失是在及时性与误警控制之间取得折中。

## 3. 特征消融

实验使用常规 test split，每个训练随机种子测试 500 个 episode。

| 特征 | Event Precision | Event Recall | Event F1 | DR@1s | Mean Delay (s) |
|---|---:|---:|---:|---:|---:|
| Position Only | 0.953 ± 0.005 | 0.819 ± 0.003 | 0.881 ± 0.001 | 0.215 ± 0.003 | 4.790 ± 0.025 |
| Local | **0.982 ± 0.008** | 0.961 ± 0.002 | 0.971 ± 0.003 | 0.431 ± 0.002 | 3.011 ± 0.021 |
| Full | 0.962 ± 0.016 | **0.989 ± 0.002** | **0.975 ± 0.009** | **0.655 ± 0.021** | **1.699 ± 0.151** |

>特征消融结果表明，不同信息源之间的互补可以有效提高检测性能。Position Only仅包含GPS位置与ISAC定位结果之间的差异，这类差异既可能由欺骗攻击引起，也可能由ISAC测量噪声、定位误差和无人机机动产生，因此正常状态与弱攻击状态的特征分布存在较大重叠，其Event F1仅为0.881±0.001。Local Features 加入基站测得的距离、径向速度和方向统计量后，模型可以同时判断位置误差是否伴随运动学和多基站观测异常，从而将随机测量误差与具有持续结构的GPS欺骗区分开，使Event F1提高至0.971±0.003。Full Features 进一步比较GPS推导的机间距离与无人机间直接ISAC测距，当部分无人机受到攻击时，GPS相对几何关系会与不受攻击的物理测距产生系统性偏差；这一偏差不依赖单个基站定位结果，因此能够更早形成攻击证据，平均延迟缩短至1.699±0.151 s。由于机间测距噪声和动态邻居切换造成的瞬态不一致，导致Full Features 的误报警率略高于Local，尤其当邻居集合或链路质量变化时，最小/最大距离差可能短暂偏离训练分布。由此可见，机间特征主要改善召回率和检测速度，但也引入了新的噪声来源，这解释了Full在Recall和Delay上占优、而Local在Precision和FAR上更好的权衡关系。

## 4. 跨 RCS 泛化

模型均固定在 RCS=6 上训练，分别测试 RCS=3、6、9、12、15、18、21、24；每个 RCS 和训练随机种子包含 1000 个 episode。

### 4.1 总体 Event F1 与平均延迟

### 4.2 结果解释

- RCS=3 是三种特征配置共同的困难条件，但 Full 仍维持 0.947 ± 0.011 的 Event F1，明显优于 Local 的 0.862 ± 0.034。
- Full 在全部 RCS 上均获得最高 Event F1 和最低 Mean Delay，且随着感知质量提高，F1 从 0.947 上升至 0.995，延迟从 1.785 s 下降至 1.334 s。
- Local 对中高 RCS 也较稳健，在 RCS=6–24 的 Event F1 为 0.967–0.988，但低 RCS=3 时下降更明显。
- Position Only 对 RCS 分布变化最敏感：RCS=6–9 附近表现尚可，之后 Precision 随 RCS 增大而下降，使 Event F1 在 RCS=24 降至 0.633。说明只依赖位置差异会受到测试分布变化影响。

## 8. 1h 长时多攻击测试

该实验仅评估 Full B+S+U。测试集为固定 RCS=6 的 20 条 1h episode，其中 16 条包含多次攻击、4 条为纯净 episode；每条轨迹包含 8 架无人机，共有 277 个群组攻击事件和 682 个逐无人机攻击事件。三次评估使用相同测试集和不同训练随机种子的模型。

| 0.959 ± 0.015 | 0.963 ± 0.004 | 0.961 ± 0.007 | 0.179 ± 0.067 | 0.083 ± 0.144 | 2.437 ± 0.246 | 0.700 ± 0.100 |

### 8.2 长时稳定性

| 1h 时间段 | Event Recall | Mean Delay (s) | FAR (/UAV·h) |
|---|---:|---:|---:|
| 0–15 min | 0.936 ± 0.008 | 3.244 ± 0.356 | 0.153 ± 0.051 |
| 15–30 min | 0.971 ± 0.005 | 2.229 ± 0.200 | 0.180 ± 0.068 |

四个时间段没有呈现随运行时间持续恶化的趋势。第一时间段 Recall 较低且延迟较高，但之后三个时间段保持在 0.966–0.975；由于各时间段的攻击类型和强度组成并未在该表中控制，不能直接将差异归因于模型热身或状态重置。

### 8.3 长期运行中的困难条件

| 分层 | 条件 | Event Recall | Mean Delay (s) |
|---|---|---:|---:|
| 攻击类型 | Random | 0.991 ± 0.005 | 0.991 ± 0.160 |
| 攻击类型 | Replay | 0.948 ± 0.006 | 1.845 ± 0.334 |
| 攻击类型 | Stealth | 0.952 ± 0.008 | **4.498 ± 0.317** |
| 强度 | Weak | **0.908 ± 0.011** | **3.816 ± 0.305** |
| 强度 | Medium | 0.986 ± 0.002 | 2.273 ± 0.352 |
| 强度 | Strong | 1.000 ± 0.000 | 1.193 ± 0.082 |
| 攻击顺序 | 每架 UAV 的首次攻击 | 0.945 ± 0.008 | 2.898 ± 0.204 |
| 攻击顺序 | 同一 UAV 的后续攻击 | 0.967 ± 0.004 | 2.333 ± 0.256 |
| GRU 分段 | 跨重置边界 | 0.955 ± 0.005 | 2.649 ± 0.265 |
| GRU 分段 | 位于单个分段内 | 0.975 ± 0.004 | 2.136 ± 0.234 |

### 8.4 结果解释

- 长时 Event F1 为 0.961 ± 0.007，表明模型能够在单条轨迹中重复报警和重新布防，而不是只检测第一次攻击。
- 同一 UAV 的后续攻击表现没有下降，Recall 反而比首次攻击高约 2.2 个百分点；未观察到报警状态无法重新启用的问题。
- Stealth 和 Weak 攻击仍是长期运行中的主要瓶颈，与短时分层实验结论一致。
- 跨 GRU 重置边界事件的 Recall 比分段内事件低约 2.0 个百分点，Mean Delay 高约 0.51 s，说明上下文重放显著缓解了状态截断问题，但边界效应尚未完全消除。
- Clean episode alarm probability 的估计仅基于每个模型 4 条纯净 episode，取值粒度较粗，因此 0.083 ± 0.144 不能单独作为稳定的误报警概率估计；FAR 利用了更长的正常暴露时间，更适合作为主要误报警指标。

## 9. 综合判断与后续建议

### 9.1 当前可以支持的结论

- Local B+S 已能提供很强的检测能力；机间 ISAC 一致性特征 U 的主要贡献是提高召回、提前报警并增强低 RCS 鲁棒性。
- Full 是综合 Event F1、Recall、Delay 和跨 RCS 泛化后的首选模型，但 Local 在追求最低误报警时更有优势。
- 系统的主要困难场景已集中到 Weak Stealth、低 RCS 和 GRU 重置边界附近，而不是一般的 Random/Replay 强攻击。
- 邻域大小存在明确的精确率—召回率—延迟权衡，当前数据不支持“邻域越大越好”。

### 9.2 报告限制

- 所有模型间均值比较只有 3 个训练随机种子，样本标准差可以描述训练波动，但正式显著性检验功效有限。
- 跨 RCS、攻击分层和邻域敏感性使用同一组训练模型及固定测试数据；不能把 episode 数量当作独立模型重复来夸大统计显著性。
- 1h 测试目前只覆盖 Full、RCS=6 和同一个长期数据集，尚未验证 Local/Position、跨 RCS 或不同长期数据随机种子的稳定性。
- 邻域敏感性中 Local 和 Position Only 的水平线是因为其输入不包含 U，并非对每个 $K_n$ 重新训练了独立模型。

### 9.3 建议的补充实验

1. 将训练随机种子从 3 增加到至少 5，以提高特征消融和邻域比较的统计功效。
2. 对 Weak Stealth 单独增加样本，并分析延迟长尾、漏检事件和误报警触发原因。
3. 增加至少一个不同随机种子的 1h 测试集，区分模型随机性与长期数据集随机性。
4. 若部署目标优先考虑 F1，可重点复核 $K_n=4$；若优先考虑时延，则同时保留 $K_n=3$ 作为基准。
5. 对跨 GRU 重置边界事件检查上下文长度，并比较 30 s 与更长上下文重放策略。
