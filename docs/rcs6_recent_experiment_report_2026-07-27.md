# 近期实验结果汇报

## 1. 当前研究设置

当前主任务为：利用 ISAC 物理一致性信息和 GRU 序列模型，对单架无人机上的 GPS 欺骗事件进行独立检测和报警。

主实验配置如下：

- 无人机数量：8；
- 有效基站数量：4；
- 单个 episode 时长：60 s；
- 仿真步长：0.1 s；
- 主轨迹：S 型轨迹；
- 攻击类型：Random、Replay、Stealth；
- 攻击强度：Weak、Medium、Strong；
- 主训练条件：RCS=6；
- 检测模型：单层 GRU，隐藏维度为 64；
- 模型逐 step 输出攻击概率；
- 判断阈值：0.5；
- 连续 \(K=5\) 个阳性 step 形成正式报警；
- 每个攻击事件只统计首次报警；
- 训练随机种子：20260716、20260717、20260718。

当前主特征为 9 维：

$$
6\text{维基站测量残差}
+
2\text{维GPS--ISAC位置差}
+
1\text{维邻域异常对比特征}.
$$

当前完整训练目标为：

$$
\mathcal L
=
\mathcal L_{\mathrm{BCE}}
+
\lambda_d\mathcal L_{\mathrm{early}}
+
\lambda_f\mathcal L_{\mathrm{FA}},
$$

其中：

$$
\lambda_d=0.01,\qquad \lambda_f=0.5.
$$

以下主表结果均为三个训练随机种子在相同内部 test split 上的均值与样本标准差。跨 RCS 实验固定使用 RCS=6 训练的模型，在独立且攻击元数据配对的 RCS=3、6、9、12 测试集上评价。

## 2. 损失函数总体比较

| 方法 | Event Precision | Event Recall | Event F1 | FAR / UAV·h | 平均延迟 / s |
|---|---:|---:|---:|---:|---:|
| BCE | 0.912 ± 0.007 | **0.979 ± 0.001** | 0.944 ± 0.003 | 1.395 ± 0.122 | 2.869 ± 0.033 |
| Weighted BCE | 0.249 ± 0.012 | 0.967 ± 0.007 | 0.396 ± 0.016 | 43.115 ± 2.620 | **2.102 ± 0.025** |
| Binary Focal Loss | 0.912 ± 0.006 | 0.978 ± 0.001 | 0.944 ± 0.003 | 1.390 ± 0.104 | 2.870 ± 0.020 |
| Event-aligned Loss | **0.959 ± 0.009** | 0.974 ± 0.001 | **0.966 ± 0.005** | **0.623 ± 0.134** | 2.940 ± 0.057 |

### 2.1 Event Loss 相对 BCE 的变化

| 指标 | 绝对变化 | 相对变化 |
|---|---:|---:|
| Event Precision | +0.047 | +5.15% |
| Event Recall | −0.005 | −0.51% |
| Event F1 | +0.022 | +2.33% |
| FAR / UAV·h | −0.772 | −55.34% |
| 平均检测延迟 | +0.071 s | +2.47% |

Event Loss 的主要优势不是提高 Recall 或缩短延迟，而是：

1. 显著提高事件级 Precision；
2. 将事件级 F1 从 0.944 提高到 0.966；
3. 将误报率从 1.395 降低到 0.623 次/UAV·h；
4. 在上述改进下仍保持 0.974 的事件 Recall。

> Event-aligned Loss 能够在保持较高事件检出率的同时改善 Precision–FAR 权衡，从而提高整体事件级检测可靠性。

Focal Loss 与普通 BCE 基本一致，说明单纯强调困难 step 并没有解决最终的事件报警问题。

Weighted BCE 使模型产生明显的过度报警倾向。虽然检出事件后的条件平均延迟较短，但其 Precision 仅为 0.249，FAR 高达 43.115 次/UAV·h，因此不能将该延迟优势解释为有效的早检测能力。

## 3. Event Loss 组成消融

| 训练目标 | Event Precision | Event Recall | Event F1 | FAR / UAV·h | 平均延迟 / s |
|---|---:|---:|---:|---:|---:|
| BCE | 0.912 ± 0.007 | 0.979 ± 0.001 | 0.944 ± 0.003 | 1.395 ± 0.122 | 2.869 ± 0.033 |
| BCE + Early | 0.891 ± 0.005 | **0.981 ± 0.000** | 0.934 ± 0.003 | 1.771 ± 0.098 | **2.815 ± 0.027** |
| BCE + FA | 0.950 ± 0.012 | 0.976 ± 0.002 | 0.963 ± 0.005 | 0.762 ± 0.199 | 2.898 ± 0.024 |
| Event Loss | **0.959 ± 0.009** | 0.974 ± 0.001 | **0.966 ± 0.005** | **0.623 ± 0.134** | 2.940 ± 0.057 |

### 3.1 Early 项的作用

BCE+Early 相对 BCE：

- 平均延迟缩短 0.054 s；
- Recall 提高 0.002；
- Precision 降低 0.021；
- F1 降低 0.010；
- FAR 增加约 27.0%。

这说明 Early 项确实使模型更倾向于尽早报警，但单独使用会增加正常区间误报，导致总体事件检测质量下降。

### 3.2 FA 项的作用

BCE+FA 相对 BCE：

- Precision 提高 0.038；
- F1 提高 0.019；
- FAR 降低约 45.4%；
- Recall 仅下降 0.003；
- 延迟增加 0.029 s。

因此，当前 Event Loss 性能提升的主要来源是事件级误报约束。

### 3.3 完整 Event Loss

完整 Event Loss 相对 BCE+FA：

- F1 进一步提高 0.003；
- FAR 进一步降低约 18.2%；
- Recall 下降 0.002；
- 平均延迟增加 0.042 s。

这表明 Early 与 FA 联合使用后存在交互作用。完整损失取得了最佳 F1 和最低 FAR，但没有取得最短延迟。

## 4. 特征消融结果

| Full Feature | 9 | **0.959 ± 0.009** | 0.974 ± 0.001 | **0.966 ± 0.005** | **0.623 ± 0.134** | 2.940 ± 0.057 |
|---|---:|---:|---:|---:|---:|---:|
| 特征集合 | 维度 | Event Precision | Event Recall | Event F1 | FAR / UAV·h | 平均延迟 / s |
| only position | 3 | 0.925 ± 0.010 | 0.826 ± 0.003 | 0.873 ± 0.003 | 0.987 ± 0.145 | 4.863 ± 0.107 |
| Local | 8 | 0.955 ± 0.013 | **0.975 ± 0.005** | 0.965 ± 0.004 | 0.676 ± 0.202 | **2.868 ± 0.025** |

### 4.1 BS残差是主要检测信息来源

删除 6 维 BS 残差后：

- Recall 从 0.974 降至 0.826；
- F1 从 0.966 降至 0.873；
- FAR 从 0.623 增至 0.987 次/UAV·h；
- 平均延迟从 2.940 s 增至 4.863 s。

这能够直接支撑：

> ISAC 基站级物理一致性残差为当前检测器提供了主要判别能力。

### 4.2 标称RCS=6下的邻域增益较小

完整 F9 相对无邻域 F8：

- Precision 提高 0.004；
- Recall 降低 0.001；
- F1 提高 0.001；
- FAR 降低约 7.8%；
- 平均延迟增加 0.072 s。

因此，仅根据同分布 RCS=6 内部测试，邻域特征只能被描述为提供了有限的误报抑制，不能声称带来显著的全面提升。

当前尚未完成“仅去除 2 维 GPS–ISAC 位置差、保留 BS 残差与邻域特征”的独立消融，因此暂时不能单独量化这 2 维位置差特征的贡献。

### 5.1 低质量RCS=3

F9 相对 F8：

- Precision 提高 0.158；
- F1 提高 0.103；
- FAR 降低 5.174 次/UAV·h，即降低约 52.7%；
- Recall 下降 0.012；
- 延迟增加 0.186 s。

这是当前邻域特征最有说服力的结果，说明当测试时 ISAC 质量低于训练条件时，邻域特征能够缓解本机物理特征退化所引起的误报。

### 5.2 标称RCS=6

F9 相对 F8：

- F1 提高 0.006；
- FAR 降低约 25.0%；
- Recall 和平均延迟变化较小。

这说明邻域特征在标称条件下主要提供误报抑制，而不是增加检出率。

### 5.3 高质量RCS=9和12

在 RCS=9 和 12 下，F9 相对 F8 的 F1 分别降低 0.013 和 0.029，FAR 分别增加约 116.8% 和 295.1%。

这说明当前邻域特征存在测试时质量分布敏感性。可能原因包括：

- 模型和标准化参数在 RCS=6 上拟合；
- RCS提高后本机残差分布改变；
- 邻域对比特征与本机特征的相对尺度发生改变；
- 网络仍按照训练时的特征关系解释邻域特征，从而产生失配。

因此，邻域特征应被定义为：

> 面向低质量或退化 ISAC 条件的条件性鲁棒性补偿。

8. 当前能够支撑的论文结论

### 结论一：Event-aligned Loss有效改善事件级报警可靠性

相较 BCE、Weighted BCE 和 Focal Loss，Event Loss 在维持高 Recall 的同时提高了 Precision 和 F1，并显著降低 FAR。

### 结论二：误报损失是Event Loss性能提升的主要来源

Early 项单独使用可以略微缩短延迟，但会增加误报；FA 项能够显著降低 FAR 并提高 F1；完整 Event Loss 在当前权衡下取得最佳 F1 和最低 FAR。

### 结论三：ISAC基站残差是主要检测信息来源

删除 BS 残差后，Recall、F1、FAR和检测延迟均明显恶化，说明基站级物理一致性残差构成检测器的核心信息基础。

### 结论四：邻域特征提供有条件的鲁棒性补偿

邻域特征在 RCS=6 标称条件下增益有限，但在测试时 RCS 降至 3 时显著提高 Precision 和 F1，并降低误报。其作用具有明确适用边界，而不是普遍性能提升。

### 结论五：RCS=6适合作为论文主线

RCS=6位于当前考察范围的中间条件：

- 能够保证基本 ISAC 检测能力；
- 不会像过高 RCS 一样使任务过于容易；
- 可以向下测试 RCS=3 的质量退化；
- 可以向上测试 RCS=9、12 的质量变化；
- 便于同时讨论标称性能和测试时鲁棒性。

## 汇报总结

当前最适合用于论文摘要或结论的总述为：

> 实验结果表明，所提出的**事件对齐训练方法**通过直接**约束正式报警行为**，在**保持较高事件检出率的同时提高事件级精度并降低误报率**。I**SAC基站级物理一致性残差构成检测器的主要判别信息**，而邻域异常对比信息可在测试时ISAC质量退化的条件下进一步缓解误报，但其增益具有明确的质量依赖性。
