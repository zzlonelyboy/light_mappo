# 基于ISAC感知与事件级优化的无人机群GPS欺骗检测

## 研究总结与论文蓝图

**日期**: 2026-07-25 | **状态**: 实验矩阵完成，待撰写

---

## 一、核心论点

GPS欺骗检测需要两件事：(1) 设计合适的检测特征——ISAC感知提供GPS免疫的物理测量，邻域对比利用多UAV天然冗余做互校验；(2) 设计对齐部署指标的训练目标——event-likelihood loss将优化从步级分类转为事件级首警检测。

---

## 二、两条贡献

### C1: ISAC辅助的检测特征设计（F8→F9）

**ISAC自检测特征（F8, 8维）——独立感知源**

6维BS链路残差（4个锚点的距离/多普勒/方向残差的mean和max）+ 2维GPS-ISAC位置差异（误差范数 + 航向投影）。ISAC基站是固定地面设施，测量免疫GPS欺骗。

> "If GPS is being spoofed, the expected range/Doppler from GPS will diverge from ISAC measurements, producing non-zero link residuals."

**邻域有符号异常对比（F8→F9, +1维）——跨UAV互校验**

```
signed_contrast = ||GPS位置 − ISAC位置|| − median(K个最近邻居的偏差)
> 0：比邻居更异常（攻击嫌疑）
≈ 0：与邻居一致（正常）
< 0：比邻居更正常（ISAC噪声）
```

无需运行时通信——特征由ISAC定位输出预计算。

**证据**：Table 1, F8→F9: FAR −19%（RCS=6），−11%（RCS=3），3-seed一致正向。ISAC贡献由no-BS消融独立验证。

### C2: Event-Likelihood Loss（步级→事件级优化）

用可微K步确认机制替代逐步BCE：

1. 滑动logit窗口上的归一化soft-minimum实现软K步确认
2. 条件hazard→攻击区间内的首警分布
3. 三项损失：L_det（漏检）+ L_delay（检测延迟）+ L_FA（虚警）
4. λ_det=0：步级BCE分量已满足检测需求；事件项专门处理BCE无法解决的延迟和虚警

**证据**：Table 1, BCE→event_lik: FAR −59%（RCS=6），−55%（RCS=3），跨特征集和感知条件一致。

## 三、最终特征方案

**F9 = 8维ISAC自检测特征 + 1维有符号邻域对比。F11已弃用。**

11维变体（增加common_projection和geometry_error）在16/16组对比中FAR高于F9。F11不出现在论文中。

## 六、五条核心发现

1. **Event-likelihood loss 是绝对主导因素**：FAR −55~60%，跨RCS条件和特征集一致。这是首要贡献。

2. **F9邻域特征在S-curve上一致有效**：FAR −11~19%，3-seed全正向。增益在感知降级时增长。

3. **RCS=3训练产生更强的跨轨迹泛化**：反直觉——噪声ISAC充当隐式正则化器。

4. **邻域特征是条件性鲁棒机制，非通用增强器**：在S-curve/circle/helix上有效；在straight上失效。≥50%UAV被攻击时失效。

5. **ISAC BS链路残差是不可替代的信息源**：移除后检测崩溃（F1 −12%，FAR ×4，来自多轨迹BCE数据）。

## 十、摘要

GPS欺骗可导致无人机群偏离预定航线甚至碰撞。基于GPS信号物理特征（到达角、信号强度）的传统检测方法可被攻击者同步伪造，而惯性传感器融合方法受限于漂移与成本。本文提出一种通感一体化（ISAC）辅助的无人机群GPS欺骗事件级检测框架，包含两个核心设计：（1）ISAC辅助的检测特征集——8维ISAC链路残差与位置差异提供GPS免疫的物理感知，外加单维有符号邻域异常对比实现零通信跨无人机互校验；（2）事件级似然损失函数——以可微K步确认机制替代逐步二元交叉熵，将训练目标从步级分类准确率对齐至事件级首警分布。在S-curve轨迹上，所提方法于RCS=6条件下将虚警率降低67%（事件F1=0.967），于RCS=3条件下降低59%（事件F1=0.945）。置信度分箱和攻击规模分层分析表明，邻域特征的边际价值随ISAC感知质量下降而增长，但在半数以上无人机同时被攻击时失效。跨轨迹泛化实验显示，低感知质量训练可产生更强的轨迹鲁棒性。
