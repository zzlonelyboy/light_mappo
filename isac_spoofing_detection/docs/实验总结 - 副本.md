# ISAC 欺骗检测实验结果总结

随着无人机集群在巡检、物流和协同感知等场景中的应用，GPS 欺骗已成为影响导航安全与编队协同的重要风险。现有信号级检测方法通常依赖原始 GNSS 观测量或专用接收机处理，多源融合方法则需要惯导、视觉等辅助设备，增加了系统开销。此外，学习型检测器多以单个时间步为训练单位，而实际系统通常经过连续多步确认后才触发事件报警，训练目标与部署规则之间存在粒度差异。为此，本文提出一种 ISAC 辅助的 GPS 欺骗事件检测方法，融合多基站距离、径向速度、方向及 GPS 与 ISAC 位置差异，并根据无人机间 ISAC 测距动态选择近邻，通过比较实测距离与 GPS 推算距离构造局部几何一致性特征。模型采用 GRU 学习异常的时序变化，并利用基于 Soft-Min 的可微确认映射，引入早期检测和正常区间无报警约束。实验表明，基站 ISAC 特征是主要判别依据；加入邻域特征后，Event Recall 从 0.961 提高至 0.989，DR@1s 从 0.431 提高至 0.655，平均延迟从 3.011 s 降至 1.699 s，但部分 Replay 和 Stealth 条件下误报警有所增加。相较逐步 BCE，事件对齐训练将 Event F1 从 0.946 提高至 0.975。完整模型多种RCS条件下都取得了较好的检测效果，说明群内邻域约束与事件级训练能够提高弱攻击检测和跨感知质量适应能力。

## 1. 实验设置与指标口径

### 1.1 三种特征配置

| 简称          | 配置          | 维度 | 内容                                                |
| ------------- | ------------- | ---: | --------------------------------------------------- |
| Position Only | Only Position |    2 | GPS 与基站 ISAC 位置差异                            |
| Local         | Local         |    8 | 6 维基站 ISAC 统计量 + 2 维位置差异，不使用邻机特征 |
| Full          | Full          |   10 | Local 特征 + 2 维机间 ISAC 测距一致性特征           |

模型均在 RCS=6 的训练集上训练。Full 模型的基准邻域大小为 $K_n=3$。

部署时使用连续 $K_c=5$ 步确认报警；这里 $K_n$ 表示邻机数量，$K_c$ 表示报警确认步数。

### 1.2 指标解释

| 指标            | 含义                                       |
| --------------- | ------------------------------------------ |
| Event Precision | 事件级报警精确率                           |
| Event Recall    | 事件级攻击召回率                           |
| Event F1        | Event Precision 与 Event Recall 的调和平均 |
| FAR             | 每无人机小时的误报警事件数                 |
| DR@1s           | 攻击开始后 1 秒内完成检测的事件比例        |
| Mean Delay      | 已成功检测事件的条件平均延迟               |

## 2. 训练目标

### 2.1 当前的训练目标

当前 Event Loss 为：

$$
\mathcal L
=
\mathcal L_{\mathrm{BCE}}
+
\lambda_d\mathcal L_{\mathrm{early}}
+
\lambda_f\mathcal L_{\mathrm{FA}},
$$

其中：

$$
\lambda_d=0.01,
\qquad
\lambda_f=2.
$$

因此，方法的实际重点是：

- BCE 保证基础逐步分类能力；
- Early 项提供较早确认倾向；
- FA 项抑制正常区间形成正式误报事件。

### 2.2 损失函数总体比较

- RCS=6 主数据集,使用相同的测试数据

| 方案             | Event Precision   | Event Recall      | Event F1          | FAR (/UAV·h) ↓    | DR@1s             | Mean Delay (s) ↓  |
| ---------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- |
| BCE              | 0.899 ± 0.010     | 0.997 ± 0.001     | 0.946 ± 0.006     | 1.637 ± 0.181     | 0.695 ± 0.004     | 1.273 ± 0.029     |
| Weighted BCE     | 0.532 ± 0.035     | **0.999 ± 0.000** | 0.693 ± 0.030     | 13.011 ± 1.809    | **0.889 ± 0.007** | **0.631 ± 0.021** |
| Focal            | 0.892 ± 0.019     | 0.997 ± 0.001     | 0.942 ± 0.010     | 1.782 ± 0.342     | 0.706 ± 0.008     | 1.246 ± 0.052     |
| Event-Likelihood | **0.962 ± 0.016** | 0.989 ± 0.002     | **0.975 ± 0.009** | **0.574 ± 0.242** | 0.655 ± 0.021     | 1.699 ± 0.151     |

>传统 BCE、Weighted BCE 和 Focal Loss 均以单个时间步为优化单位，而系统在部署时采用连续 $K_c=5$ 步确认并按事件统计性能，两者的粒度差异使少量连续误判也可能形成完整的误报警事件。BCE 和 Focal Loss 的结果接近，Weighted BCE 虽提高了召回率和早期检出率，却使 FAR 增至 13.011 次/UAV·h，说明调整逐步分类权重不能解决事件级误警问题。当前 Event-aligned Loss 在 BCE 基础上加入首次报警时刻和正常区间无报警约束，使 Event Precision 从 0.899 提高至 0.962、Event F1 从 0.946 提高至 0.975，同时保持 0.989 的 Event Recall。尽管其早期检出率和平均延迟略有退化，这些结果仍表明，将逐步概率学习与连续确认规则纳入同一训练目标，能够减少无效报警，并提高事件级检测的整体可靠性。

### 2.3 Event Loss 组成消融

| 方案       | Event Precision   | Event Recall      | Event F1          | FAR (/UAV·h) ↓    | DR@1s             | Mean Delay (s) ↓  | Step F1           |
| ---------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- | ----------------- |
| Early-only | 0.777 ± 0.022     | **0.997 ± 0.002** | 0.873 ± 0.014     | 4.219 ± 0.542     | **0.772 ± 0.021** | **1.013 ± 0.055** | **0.961 ± 0.002** |
| FA-only    | **0.979 ± 0.007** | 0.985 ± 0.003     | **0.982 ± 0.003** | **0.311 ± 0.107** | 0.573 ± 0.013     | 1.946 ± 0.098     | 0.946 ± 0.003     |
| Early+FA   | 0.962 ± 0.016     | 0.989 ± 0.002     | 0.975 ± 0.009     | 0.574 ± 0.242     | 0.655 ± 0.021     | 1.699 ± 0.151     | 0.948 ± 0.002     |

> 组成消融表明，Early 项与 FA 项分别侧重检测及时性和误报警控制。Early-only 通过优化攻击事件内首次报警的条件期望延迟，使模型更早触发，因而获得 较短的平均延迟。但该项不约束正常区间内的连续报警，当正常状态与攻击初期的特征分布重叠时，提前触发也会增加误警，使 Event Precision 降至 0.777。其 Step F1 为 0.961，而 Event F1 仅为 0.873，进一步说明较好的逐步分类结果未必能转化为可靠的事件报警。FA-only 通过抑制正常区间中可形成 $K_c$步连续触发的预测片段，将 Event Precision 和 Event F1 分别提高至 0.979 和 0.982，并将 FAR 降至 0.311 次/UAV·h，但更保守的判决也降低了早期检出率。加入 Early 项后，Early+FA 将 DR@1s 从 0.573 提高至 0.655，平均延迟缩短 0.247 s，同时 Event F1 降至 0.975、FAR升至0.574次/UAV·h。因此，完整损失是在及时性与误警控制之间取得折中。

## 3. 特征消融

实验使用常规 test split，每个训练随机种子测试 500 个 episode。

| 特征          |   Event Precision |      Event Recall |          Event F1 |             DR@1s |    Mean Delay (s) |
| ------------- | ----------------: | ----------------: | ----------------: | ----------------: | ----------------: |
| Position Only |     0.953 ± 0.005 |     0.819 ± 0.003 |     0.881 ± 0.001 |     0.215 ± 0.003 |     4.790 ± 0.025 |
| Local         | **0.982 ± 0.008** |     0.961 ± 0.002 |     0.971 ± 0.003 |     0.431 ± 0.002 |     3.011 ± 0.021 |
| Full          |     0.962 ± 0.016 | **0.989 ± 0.002** | **0.975 ± 0.009** | **0.655 ± 0.021** | **1.699 ± 0.151** |

>特征消融结果表明，不同信息源之间的互补可以有效提高检测性能。Position Only仅包含GPS位置与ISAC定位结果之间的差异，这类差异既可能由欺骗攻击引起，也可能由ISAC测量噪声、定位误差和无人机机动产生，因此正常状态与弱攻击状态的特征分布存在较大重叠，其Event F1仅为0.881±0.001。
>
>Local Features 加入基站测得的距离、径向速度和方向统计量后，模型可以同时判断位置误差是否伴随运动学和多基站观测异常，从而将随机测量误差与具有持续结构的GPS欺骗区分开，使Event F1提高至0.971±0.003。
>
>Full Features 进一步比较GPS推导的机间距离与无人机间直接ISAC测距，当部分无人机受到攻击时，GPS相对几何关系会与不受攻击的物理测距产生系统性偏差；这一偏差不依赖单个基站定位结果，因此能够更早形成攻击证据，平均延迟缩短至1.699±0.151 s。
>
>由于机间测距噪声和动态邻居切换造成的瞬态不一致，导致Full Features 的误报警率略高于Local，尤其当邻居集合或链路质量变化时，最小/最大距离差可能短暂偏离训练分布。由此可见，机间特征主要改善召回率和检测速度，但也引入了新的噪声来源，这解释了Full在Recall和Delay上占优、而Local在Precision和FAR上更好的权衡关系。

## 5. 攻击类型及强度二级分层

在匹配的 RCS=6 条件下，按照攻击类型和 Weak/Medium/Strong 强度进行二级分层。

![RCS=6 下攻击类型与强度二级分层](D:\Codes\project_spoofing_detect\light_mappo\isac_spoofing_detection\experimentsNew\direct_inter_uav_rcs6_fa2_ablation\cross_rcs_csv\matlab_figures\rcs6_attack_type_severity_3features.png)



>Position Only 仅利用单机 GPS 与基站 ISAC 的位置差异，对偏差尚未充分积累的弱攻击辨识能力有限，尤其难以在连续确认条件下稳定检测 Weak Random，但对形成持续位置滞后的 Replay 以及逐渐累积的中强 Stealth 仍能实现较高召回，只是检测较慢。
>
>Local B+S 加入基站测距、径向速度和方向信息后，能够结合运动状态判断位置差异是否异常，因此在 Replay 和 Stealth 中通常取得较高 Precision 与 Event F1；然而，Weak Random 的扰动逐步独立且幅值较小，异常证据缺乏持续性，Local 的召回仍受限制。
>
>Full B+S+U 进一步比较 GPS 推算的机间距离与无人机间 ISAC 测距，局部随机扰动会同时破坏多个相对几何约束，因而对 Weak Random 的提升最明显，并普遍缩短检测延迟。相较之下，Replay 可能部分保留编队的相对几何关系，邻域特征提供的增益有限。
>
>而Stealth 在攻击初期也只产生缓慢漂移且漂移方向相近，使机间特征提供的信息较为有限，测距波动的额外敏感性还会增加误报警，因此 Full 在 Weak Replay 和各强度 Stealth 上的表现并未明显优于Local。
>
>随着攻击增强，单机位置差异和基站 ISAC 特征已足以形成稳定证据，三种配置之间的召回差距随之缩小，说明机间特征的主要价值在于提高弱攻击的可观测性和检测速度，而非在所有攻击条件下均带来一致的 F1 增益。



## 6. 攻击类型分层



![按攻击类型分层的跨 RCS 结果](D:\Codes\project_spoofing_detect\light_mappo\isac_spoofing_detection\experimentsNew\direct_inter_uav_rcs6_fa2_ablation\cross_rcs_csv\matlab_figures\cross_rcs_by_attack_type_3features.png)



>特征冗余决定了模型对感知质量变化的适应能力。Position Only 仅依据 GPS 与基站 ISAC 的位置残差进行判断，RCS=3 时较大的 ISAC 测量噪声会使正常残差接近攻击残差，导致三类攻击的 Precision 和 F1 同时下降。当 RCS 高于训练值后，其 Precision 再次持续降低，说明该模型依赖 RCS=6 下的残差尺度，而非学习到稳定的攻击模式，残差分布向高噪声或低噪声方向偏移都会破坏决策校准。
>
>Local 加入基站测距、径向速度和方向信息后，模型不再依赖单一位置差异，因此在 RCS=3至24 范围内保持较稳定的 F1，其中 Replay 和 Stealth 的优势尤为明显。
>
>Full 进一步引入机间测距一致性，尽管基站和机间 ISAC 测量会随 RCS 同步退化，相对几何约束仍为局部 GPS 异常提供补充证据，使 Full 在低 RCS 下保持更高召回，并在各 RCS 上获得最短检测延迟。这种收益对破坏机间几何关系的 Random 最明显，而 Replay 可能部分保留编队相对结构，Stealth 又需要等待渐进偏差充分累积，因此两者的机间特征增益较小，Local 在部分条件下仍具有更高 Precision 或 F1。
>
>随着 RCS 提高，两类 ISAC 测量噪声均减小，Local 和 Full 的性能随之改善并趋于饱和，但 Stealth 的延迟始终最高，说明其主要困难来自缓慢累积的攻击机制。

## 8. 1h 长时多攻击测试

该实验仅评估 Full B+S+U。测试集为固定 RCS=6 的 20 条 1h episode，其中 16 条包含多次攻击、4 条为纯净 episode；每条轨迹包含 8 架无人机，共有 277 个群组攻击事件和 682 个逐无人机攻击事件。

| 特征           | Event Precision    | Event Recall       | Event F1           | FAR（次/UAV·h）   | 平均时延（s）     |
| -------------- | ------------------ | ------------------ | ------------------ | ----------------- | ----------------- |
| Only Position  | 23.47% ± 14.38%    | 64.71% ± 2.76%     | 32.40% ± 16.68%    | 16.164 ± 17.387   | 6.647 ± 0.221     |
| Local Features | **96.36% ± 1.38%** | 83.77% ± 0.17%     | 89.62% ± 0.65%     | **0.138 ± 0.054** | 4.217 ± 0.082     |
| Full Features  | 95.93% ± 1.47%     | **96.29% ± 0.37%** | **96.10% ± 0.66%** | 0.179 ± 0.067     | **2.437 ± 0.246** |



>Full Features的事件Recall和F1分别达到96.29%和96.10%，平均检测时延为2.437 s，整体表现优于Local Features 。与后者相比，Full模型的Recall提高12.51个百分点，F1提高6.48个百分点，检测时延缩短约42.2%。这一优势可能来自邻域特征提供的机间几何约束：长期运行中，测量噪声、较弱的攻击信号或有限的单机观测可能造成漏检。当某架无人机受到位置欺骗时，其GPS位置所对应的机间距离会逐渐偏离直接ISAC测距，模型因而能够在单机残差尚不充分时获得额外的异常证据。Full模型的Precision比Local模型低0.43个百分点，反映出邻域测量噪声带来的轻微误报代价，但召回率和检测速度的改善更为突出。综合这些结果，邻域特征提高了检测器在长时间、多次攻击条件下的攻击覆盖率和响应速度。
